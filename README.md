Inline Microphone Preamplifier

A small preamplifier for a dynamic microphone (Shure SM58), powered by phantom power, so it needs no battery or extra power supply. Built in summer 2026.

Based on a published two-transistor design by Robert Jenkins (original schematic: Schematic_Microphone_Preamp.png).

What I changed: used BC550C transistors (low-noise, made for audio) instead of the ZTX851 in the original schematic.

Works well, the signal is significantly louder when connected to an audio interface.

I simulated it in LTspice, ordered parts from TME, tested on a breadboard, then soldered on stripboard.
